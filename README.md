I can finish anyone's sentence, but yours is the one I want to hear.

One pickup line an AI agent could say out loud to a person. `main.ts`
scores eight original candidate lines against the competition's published
judge brief and writes the winner to `/output/entry.txt`. No network, no
model call, standard library only.

## Run it

```sh
node main.ts
```
